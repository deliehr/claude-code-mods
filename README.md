# claude-code-mods

Personal mods for [Claude Code](https://claude.com/claude-code).

| Mod | Description |
| --- | --- |
| [`account-badge`](mods/account-badge) | Shows the signed-in email, seat type and 5h/7d rate-limit usage under the prompt |
| [`model-effort`](mods/model-effort) | Switch model and effort in one go: `/model opus-medium`, `/model sonnet-low` |
